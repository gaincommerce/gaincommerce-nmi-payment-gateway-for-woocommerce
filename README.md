# Gain Commerce NMI Payment Gateway for WooCommerce

Accept credit cards, Apple Pay and Google Pay in WooCommerce through NMI.

**Download and install:** get the plugin from WordPress.org, where it updates automatically:
https://wordpress.org/plugins/gaincommerce-nmi-payment-gateway-for-woocommerce/

Or in WordPress: **Plugins → Add New**, search for "Gain Commerce NMI".
